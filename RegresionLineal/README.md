## Cómo compilar y ejecutar

Se necesita tener instalado Java (JDK) y Git.

1. Clonar el repositorio:

```bash
git clone https://github.com/USUARIO/REPOSITORIO.git
cd REPOSITORIO
```

2. Compilar:

```bash
javac Ajuste_de_Funciones/*.java
```

3. Ejecutar:

```bash
java Ajuste_de_Funciones.Main
```
